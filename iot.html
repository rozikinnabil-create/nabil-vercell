📡 IoT Monitoring

Tentang Project

IoT Monitoring merupakan sistem monitoring berbasis ESP32 yang mampu mengirim data sensor secara real-time melalui internet sehingga dapat dipantau menggunakan smartphone maupun komputer.

Tujuan

  • 📡 Monitoring jarak jauh.
  • 🌐 Memanfaatkan Internet of Things.
  • 📱 Monitoring melalui smartphone.
  • 📊 Menampilkan data secara real-time.

Komponen

ESP32 DHT22 OLED Display WiFi Blynk

Fitur

  • ✅ Real-Time Monitoring
  • ✅ Wireless
  • ✅ Mobile Dashboard
  • ✅ Notification System
