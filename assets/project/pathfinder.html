🤖 Robot Pathfinder

Tentang Project

Robot Pathfinder adalah robot Line Follower berbasis ESP32 yang mampu mengikuti jalur hitam secara otomatis menggunakan sensor infrared. Robot ini dibuat sebagai media pembelajaran robotika, kontrol motor, dan sistem otomatis.

Tujuan

  • 🎯 Mengikuti garis secara otomatis.
  • 🎯 Belajar pemrograman ESP32.
  • 🎯 Mengontrol motor DC.
  • 🎯 Mempelajari sensor infrared.

Komponen

ESP32 L298N IR Sensor Motor DC Battery 18650

Fitur

  • ✅ Line Following
  • ✅ Automatic Steering
  • ✅ Fast Response
  • ✅ Efficient Power
